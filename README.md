# 🎬 Netflix Clone (HTML + CSS)

A simple Netflix landing page clone built using **only HTML and CSS**.  
It features a hero banner, trending movie posters, FAQs, and a responsive layout.

---

## 📖 About
This project replicates the look and feel of Netflix’s homepage.  
It was created for practice in **frontend development** using pure HTML and CSS, without any JavaScript or frameworks.

---

## ✨ Features
- 🎥 **Hero Banner** with promotional text and signup form  
- 📊 **Trending Movies Section** with posters and hover effects  
- 📱 **Responsive Design** for desktop and mobile screens  
- ❓ **FAQ Section** styled with collapsible boxes  
- 📌 **Footer** with useful links and language selector  

---

## 🛠️ Tech Stack
- **HTML5** – Structure and semantic elements  
- **CSS3** – Styling, layout, responsiveness  
- **SVG** – Logo and icons
